**ปรับปรุงล่าสุด:** 2026-05-12

ส่วนขยายนี้ออกแบบมาสำหรับการใช้งานภายในองค์กร เพื่อช่วยพนักงานคีย์ข้อมูลงานสำรวจจากระบบ eClaim3 ส่งเข้าเซิร์ฟเวอร์ของบริษัท (บนเครือข่ายภายในหรือ cloud private ของบริษัท)

## 1. ข้อมูลที่ส่วนขยายอ่าน

ขณะที่ผู้ใช้เปิดหน้า `https://eclaim3.blueventuregroup.co.th/esurvey/*` ส่วนขยายจะอ่านข้อมูลต่อไปนี้จาก DOM ของหน้าเพจ:

- เลขเคลม (`#lblRef_Claim_No`)
- เลขเซอร์เวย์ (`#txtBill_No`)
- ชื่อผู้คีย์ที่ login เข้า eClaim3 (`#wuHeadUser1_lblUser_Name`)
- ค่าฟอร์มสำรวจที่ผู้ใช้กรอก (จำนวน/ราคา/ประกัน/รายละเอียด — รวม 29 ช่อง)
- ประเภทงาน (`#ddlAdd_No`)

ส่วนขยายจะอ่านข้อมูลก็ต่อเมื่อผู้ใช้กดปุ่ม "บันทึกราคา", "ส่งงานใหม่" หรือ "ส่งผลงานต่อเนื่อง" ของ eClaim3 เท่านั้น ไม่มีการดักจับ keystroke หรือเก็บข้อมูลในช่วงที่ผู้ใช้กำลังพิมพ์

## 2. ข้อมูลถูกส่งไปที่ไหน

ข้อมูลที่อ่านได้จะถูกส่งไปที่ **เซิร์ฟเวอร์ของบริษัทเท่านั้น** ตาม URL ที่ผู้ใช้ตั้งค่าไว้ในหน้า popup ของส่วนขยาย เช่น:

- LAN ภายในออฟฟิศ — เช่น `http://192.168.4.122:3100`
- Cloud private — เช่น `https://key.sesurvey.cloud`

ปลายทางถูกควบคุมโดยผู้ดูแลระบบของบริษัทเท่านั้น

- **ไม่มี** การส่งไปยัง Google, Anthropic, Cloudflare, Sentry, Mixpanel, Google Analytics หรือ third-party service ใดๆ
- **ไม่มี** telemetry, analytics, crash reporting, หรือ tracking pixel
- **ไม่มี** การ sync ข้อมูลข้ามอุปกรณ์ผ่าน Chrome Sync

ผู้ดูแลระบบเซิร์ฟเวอร์ของบริษัทเป็นผู้รับผิดชอบดูแลข้อมูลตามนโยบายของบริษัทเอง

## 3. ข้อมูลที่เก็บใน browser

ส่วนขยายเก็บค่าตั้งค่าต่อไปนี้ใน `chrome.storage.local`:

- **Server URL** — ที่อยู่ของเซิร์ฟเวอร์ที่ผู้ใช้กำหนด (LAN หรือ cloud ของบริษัท)
- **API key** — shared secret ที่ตรงกับเซิร์ฟเวอร์

ค่าทั้งสองนี้เก็บแบบ per-device ไม่ sync ข้ามเครื่อง และผู้ใช้สามารถลบได้โดยถอนการติดตั้งส่วนขยายหรือเคลียร์ข้อมูลของส่วนขยายผ่าน `chrome://extensions`

## 4. Permissions ที่ส่วนขยายขอ

| Permission | เหตุผล |
|---|---|
| `storage` | เก็บ Server URL + API key ที่ผู้ใช้ตั้งค่า |
| `host_permissions: https://eclaim3.blueventuregroup.co.th/*` | content script อ่าน DOM ของหน้า eClaim3 เพื่อดึงเลขเคลม/เซอร์เวย์ |
| `optional_host_permissions: http://*/*, https://*/*` | ขอเพิ่มเฉพาะตอนที่ผู้ใช้กรอก server URL ใน popup และกด allow — เพื่อให้ background ยิง fetch ไปเซิร์ฟเวอร์ของบริษัทที่ผู้ใช้กำหนด ขอแบบกว้างเพราะแต่ละบริษัท/แต่ละสภาพแวดล้อมตั้งค่า IP/domain ต่างกัน (LAN, cloud subdomain, custom port) |

## 5. การเปิดเผยข้อมูล / ขายข้อมูล

ส่วนขยายไม่ขาย ไม่แลกเปลี่ยน และไม่ส่งต่อข้อมูลของผู้ใช้ให้บุคคลภายนอกใดๆ ทั้งสิ้น ข้อมูลทั้งหมดยังอยู่ภายในขอบเขตของบริษัทผู้ใช้
